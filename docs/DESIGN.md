## 1. 设计理念与体验原则

用户在深度专注时极易忽略横幅通知，但传统强锁屏软件往往像系统警报一样令人反感，导致用户形成「秒按 Esc 关掉」的肌肉记忆。本设计围绕以下四条原则化解这一矛盾：

1. **温和接管，而非强行打断**：全屏提醒层使用高遮蔽度的 macOS 原生磨砂材质叠加大自然鼠尾草绿（Sage）微光，让当前工作窗口柔和地退入景深后方，而非生硬的黑屏或刺眼警告色。
2. **提前预告，建立心理缓冲**：整点前 1 分钟在右上角弹出不抢焦点的轻量预告胶囊，让用户有时间保存文件、写完当前一句代码，大幅降低全屏弹出时的烦躁感。
3. **默认休息，退出只需一下**：到点直接开始休息、结束自动关闭，全程不用操作；不想休息时点一下「提前结束」。`Esc` 与 `Return` 不关闭，避免弹出时正在打字被按键误关。
4. **纯原生组件，零过度设计**：面板、设置页与窗口材质全部映射到标准 AppKit / SwiftUI 能力，确保开发成本可控、内存占用极低，且天然跟随系统外观与辅助功能偏好。

## 2. 信息架构（Information Architecture）

应用作为后台菜单栏常驻进程（`LSUIElement = YES`）运行，不占用 Dock 与 `⌘Tab` 切换列表，由四个界面表面构成：

```text
整点歇 (Menu Bar Utility)
├── 1. 菜单栏常驻图标 (Status Item)
│   └── 弹出控制面板 (Popover, 288 pt)
│       ├── 状态摘要（下次提醒时间 / 暂停倒计时 / 今日完成次数）
│       ├── 快捷操作（立即休息 / 暂停提醒：1 小时 · 今天 / 恢复提醒）
│       ├── 当前规则只读摘要（点击直达设置）
│       └── 系统操作（设置… ⌘, / 退出 ⌘Q）
├── 2. 整点前 1 分钟预告胶囊 (Non-activating HUD Panel, 312 × 68 pt)
│   ├── 60 秒倒数提示 + 保存进度引导
│   └── 快捷操作（推迟 5 分钟 / 仅收起预告）
├── 3. 全屏休息提醒覆盖层 (Multi-Display Fullscreen Overlay)
│   ├── 主屏（交互完整态）
│   │   └── 休息中（环形倒计时 / 轻量活动建议 / 提前结束），倒计时结束自动关闭
│   └── 副屏（静默同步态：统一磨砂遮罩 + 精简倒计时）
└── 4. 设置窗口 (Standard macOS Settings Window, 480 pt)
    ├── 分组一：休息节奏（休息时长 5–10 分钟 / 生效时段 / 工作日或每天）
    ├── 分组二：提醒与防打扰（1 分钟预告 / 提示音 / 会议演示自动延迟）
    ├── 分组三：系统（登录时自动启动）
    └── 底栏（预览全屏提醒按钮 / 版本信息）
```

## 3. 界面布局与尺寸规范

### 3.1 全屏休息提醒覆盖层（核心）

#### 主显示器布局
- **覆盖范围**：100% 铺满屏幕（覆盖菜单栏与 Dock 区域）。
- **内容安全容器**：水平与垂直居中，最大内容宽 **560 pt**，上下留白自适应（最小边距 64 pt），保证在 13 英寸 MacBook Air 到 32 英寸 6K Pro Display XDR 上均保持聚焦、不松散。
- **垂直视觉层级（从上到下）**：
  1. **整点时间锚点（Top Anchor）**：胶囊标签，高 `28 pt`，左右内边距 `12 pt`，圆角 `999 pt`，展示整点时间与状态（如 `正在休息 · 10:00 整点`）。与主标题间距 `24 pt`。
  2. **引导文案区（Header）**：
     - 主标题（`32 pt` Semibold）：单行居中，「离开屏幕，活动一下」。
     - 副文案（`15 pt` Regular，最大宽 `420 pt`）：「倒计时结束后自动关闭。」，与主标题间距 `10 pt`。
  3. **核心倒计时环（Timer Ring）**：与副文案间距 `36 pt`。
     - 尺寸：`208 × 208 pt`（宽屏可维持恒定，避免过大产生压迫感）。
     - 轨道粗细：底层轨道 `4 pt`，前景进度弧 `5 pt`（圆角端点 `.round`）。
     - 环内数字：`56 pt` Light/Regular，等宽数字（`monospacedDigit`），如 `05:00`；数字下方 `12 pt` 辅助标签「剩余时间」。
  4. **轻量活动建议（Micro-Activities）**：与倒计时环间距 `32 pt`。
     - 单条柔和居中的引导句，每 60 秒平缓淡入切换下一条，降低视觉元素密度，帮助视线放松。
  5. **操作区**：与引导句间距 `48 pt`，只有一个次按钮「提前结束」（高 `44 pt`，最小宽 `136 pt`，半透明磨砂描边胶囊）。点一下立即关闭，不二次确认，不计入今日完成次数。

#### 副显示器布局（Ambient Companion）
- 使用与主屏完全一致的全屏磨砂材质背景，保证视觉统一并遮挡副屏工作内容。
- 居中仅展示极简三元素：
  - `24 pt` 图标（`cup.and.saucer`）
  - `44 pt` 等宽倒计时数字（与主屏严格同步实时倒数）
  - `13 pt` 淡化提示文案：「倒计时结束后自动关闭」
- **交互**：副屏点击任意位置不直接跳过，仅轻柔将焦点激活回主屏全屏层（或保持静默），防止误点关闭。

### 3.2 菜单栏图标与弹出面板

#### 菜单栏图标（Status Item）
- 图标槽尺寸遵循 macOS 标准 `18 × 18 pt` 模板图（`isTemplate = true`），系统自动适配浅色/深色壁纸及菜单栏反色。
- **4 种可视状态**：

| 状态 | SF Symbol | 附加文本 | 透明度 / 样式 |
|---|---|---|---|
| 正常待机 | `cup.and.saucer` | 无（仅显示图标，保持极简） | 100% 模板色 |
| 整点前 1 分钟预告 | `cup.and.saucer.fill` | `1m`（11 pt 等宽） | 100% 模板色 |
| 暂停提醒中 | `moon.zzz` | 无 | 65% 不透明度 |
| 非生效时段（夜间/周末） | `cup.and.saucer` | 无 | 45% 不透明度 |

#### 弹出面板（Popover）
- **尺寸**：固定宽 **288 pt**，高度随内容自适应（约 `256–276 pt`），圆角遵循系统 Popover 标准（约 `12 pt`），内边距统一 `12 pt`。
- **结构分区**（分区之间使用 `1 px` 系统分隔线，上下留白 `8 pt`）：
  1. **状态摘要区（高约 56 pt）**：
     - 左侧：8 pt 状态指示圆点 + 主信息（`14 pt` Semibold，如「下次休息 11:00」）+ 副信息（`12 pt` 次级色，如「还有 23 分钟」）。
     - 右侧：今日统计轻胶囊（高 `26 pt`，左右内边距 `9 pt`，圆角 `8 pt`），显示 `checkmark.circle.fill`（12 pt）+ `今日 3 次`（等宽数字）。
     - *暂停态变化*：状态点转为琥珀色，主信息显示「提醒已暂停」，副信息显示「12:00 自动恢复」（或「今天不再提醒」），右侧统计位替换为紧凑 `恢复` 按钮。
  2. **快捷操作区**：
     - **主操作行**「立即休息」：全宽圆角按钮（高 `34 pt`，圆角 `8 pt`），主题色柔和填充或高对比按钮，左侧 `play.fill`，居中/左对齐文案。
     - **暂停操作行**（距主按钮 `8 pt`）：单行紧凑布局——左侧图标 `pause.circle` + 标签「暂停提醒」，右侧并排两个轻量分段按钮 `1 小时`、`今天`（每个高 `26 pt`，圆角 `6 pt`）。若处于暂停态，此行高亮当前选中的暂停项，并提供切换或取消。
  3. **当前规则速览行（高 28 pt）**：
     - 整行可点击（hover 时呈系统浅灰圆角高亮），文字 `11.5 pt` 次级色：`每次 5 分钟 · 工作日 09:00–19:00`，右侧微小 `chevron.right`，点击直接打开设置窗口。
  4. **底部菜单项（原生菜单行高 `28 pt`，圆角 `6 pt` hover 高亮）**：
     - `设置…`（左图标 `gearshape`，右快捷键 `⌘,`）
     - `1 px` 分隔线
     - `退出整点歇`（右快捷键 `⌘Q`）

### 3.3 设置窗口（Settings）

- **窗口规格**：固定宽 **480 pt**，高度随内容自适应（约 `540 pt`），标准 macOS 标题栏（仅保留关闭与最小化按钮，禁用全屏/自由缩放）。标题：「整点歇 设置」。
- **布局模式**：单页分组表单（SwiftUI `Form` + `.formStyle(.grouped)`），无需顶部 Tab 栏，一屏完成全部 7 项配置，符合现代 macOS 系统设置心智模型。
- **分组与行规格**（组间距 `16 pt`，行最小高 `40 pt`，带副说明行高 `54 pt`，组内左右内边距 `14 pt`，组卡片圆角 `10 pt`）：
  1. **分组一：休息节奏**
     - **休息时长**：左标签「休息时长」，右数值 `5 分钟`（`13 pt` Medium 等宽），下方或同行右侧放置 6 档刻度滑块（`5 / 6 / 7 / 8 / 9 / 10 分钟`，步进 1 分钟）。推荐同行右侧 180 pt 刻度滑块 + 48 pt 右对齐数值，紧凑利落。
     - **提醒生效时段**：左标签「生效时段」，右侧两个原生下拉选择器 `09:00` — `19:00`（整点选项 `00:00`–`23:00`，结束时间自动校验晚于开始时间，若结束早于开始给出清晰提示或限制）。
     - **生效日期**：左标签「重复」，右侧 Segmented Control：`仅工作日` | `每天`（宽 `168 pt`）。
  2. **分组二：提醒与防打扰**
     - **整点前 1 分钟预告**：左标题 + 副说明「提前 1 分钟右上角轻提示，方便保存手头进度」；右原生 `Toggle`。
     - **提示音**：左标题 + 副说明「休息开始与结束时播放轻柔提示音」；右原生 `Toggle`。
     - **会议或演示时自动延迟**：左标题 + 副说明「检测到全屏演示、屏幕共享或摄像头启用时自动顺延」；右原生 `Toggle`。
  3. **分组三：系统**
     - **登录时自动启动**：左标题 + 副说明「开机登录后自动在菜单栏运行」；右原生 `Toggle`。
  4. **底栏（表单下方，高 `44 pt`，左右边距 `20 pt`）**：
     - 左侧次要按钮：`预览全屏提醒`（点击后以当前配置立即预览全屏层，预览态底部注明「预览模式 · 按 Esc 退出」）。
     - 右侧低对比元信息：`版本 1.0`。

### 3.4 整点前 1 分钟预告胶囊（推荐包含）

- **位置**：主屏幕右上角，距屏幕右缘 `16 pt`，距菜单栏下缘 `12 pt`。
- **尺寸**：宽 **312 pt**，高 **68 pt**，圆角 `14 pt`。
- **窗口特性**：独立无边框非激活面板（不抢夺当前应用焦点，不打断打字），位于普通窗口之上（`.floating` 层级）。
- **内部布局**（内边距 `12 pt 14 pt`，横向 Flex，元素间距 `12 pt`）：
  - **左**：`36 × 36 pt` 柔和圆角方/圆形徽章（鼠尾草绿 14% 浅底 + `18 pt` `cup.and.saucer.fill`）。
  - **中**：
    - 上行（`13 pt` Semibold）：`1 分钟后开始整点休息`（可平滑更新倒数，如 `42 秒后开始休息`）。
    - 下行（`12 pt` 次级色）：`先保存手头进度，准备起身活动`。
  - **右**：紧凑次要按钮 `推迟`（高 `26 pt`，圆角 `6 pt`，点击直接推迟 5 分钟并关闭预告）；悬停整个卡片时左上角或右上角浮现微小 `×` 按钮（仅收起预告，不取消整点全屏提醒）。

## 4. 交互流程与状态机（含边界情况）

### 4.1 核心状态流转

```text
[待机 Idle]
   │ 距离整点 1 分钟（且预告开关打开）
   ▼
[预告 Pre-Alert (60s)] ──(点击“推迟”)──▶ [推迟 Snoozed (+5m)]
   │ 到达整点（且未命中会议/演示延迟）
   ▼
[休息中 Resting (5–10m)] ──(点击“提前结束”，一次即生效)──▶ [待机 Idle]
   │ 倒计时归零（播放柔和提示音，自动关闭）
   ▼
[待机 Idle]（今日完成次数 +1）
```

推迟后到点同样直接进入「休息中」。

### 4.2 关键交互细节

1. **「提前结束」**：点一下立即淡出关闭，不弹确认。淡出期间窗口不再接收点击和按键，连点不会触发两次。
2. **`Esc` / `Return`**：正式休息中都不关闭（预览模式下 `Esc` 退出）。提醒常在用户打字时弹出，按键不应误关。

### 4.3 边界情况处理规范

| 边界场景 | 预期行为与 UI 表现 |
|---|---|
| **多显示器环境** | 主屏（当前光标所在屏幕）显示完整交互全屏层；所有副屏同步显示「静默同步态」磨砂全屏层（仅倒计时 + 主屏提示）。休息期间若热插拔显示器，实时增删副屏遮罩窗口。 |
| **推迟时间逼近下个整点** | 若推迟目标时间距离下一个整点不足 10 分钟，自动合并至下一个整点，避免刚休完又弹窗。 |
| **暂停提醒（1 小时 / 今天）** | 暂停期间不触发 1 分钟预告与全屏层。若于 `10:20` 选「暂停 1 小时」，则于 `11:20` 自动恢复，下一次提醒为 `12:00`（面板明确标注「11:20 恢复 · 下次 12:00」）。选「今天」则暂停至下一个生效日的开始时间（如工作日模式下周五 14:00 点「今天」，则显示「周一 09:00 恢复」）。暂停中仍允许点击「立即休息」。 |
| **休息中又到整点 / 临近整点手动休息** | 若用户在 `09:57` 点击「立即休息」（5 分钟至 `10:02`），系统自动抑制 `09:59` 预告与 `10:00` 整点提醒。此外设立 **15 分钟冷却窗口**：距离上次完成休息不足 15 分钟时，自动跳过紧邻整点，避免连续打断。 |
| **全屏会议 / 演示延迟** | 触发前检测是否存在第三方独占全屏/屏幕共享/摄像头活跃（见第 9 节实现提示）。命中时静默顺延，每 5 分钟复检一次；若直到下个整点仍未结束则合并去重，绝不积压多个全屏层。菜单栏面板显示「会议中 · 提醒已顺延」。 |
| **合盖休眠后唤醒** | 休眠期间错过的整点**全部丢弃不补弹**。唤醒后若距离下一个整点不足 3 分钟，顺延或给予至少 5 分钟工作缓冲再触发，避免刚输入密码解锁就立刻全屏锁住。 |
| **工作在全屏应用 Space 中** | 覆盖层配置跨空间与全屏辅助行为，确保在全屏 Xcode / Keynote / 浏览器桌面中原地浮出，不会把用户强行切回桌面 1。 |
| **非生效时段** | 超出设置时段（如 `19:00` 后）或周末（仅工作日模式）时，菜单栏图标降至 45% 不透明度，面板显示「今日提醒已结束 · 明天 09:00 恢复」，不打扰用户；仍保留「立即休息」可用。 |

## 5. 文案规范（UX Copy · 中文）

语气定位：**温和、平实、像一位体贴但不啰嗦的同事**。避免说教感（「为了您的健康请务必…」）与命令感（「警告：您已超时工作」）。

### 5.1 全屏提醒层文案

| 位置 | 文案 | 备注 |
|---|---|---|
| 顶部时间锚点 | `正在休息 · 10:00 整点` | 手动触发显示 `正在休息 · 随时小憩`；预览显示 `预览模式` |
| 主标题 | `离开屏幕，活动一下` | — |
| 副文案 | `倒计时结束后自动关闭。` | — |
| 环内小标签 | `剩余时间` | — |
| 唯一按钮 | `提前结束` | 点一下直接关闭 |
| 副屏提示 | `倒计时结束后自动关闭` | — |

### 6.4 动效规范与「减弱动态效果」降级

动效克制在**舒缓的物理节奏**，杜绝弹跳（bounce）或闪现：

| 动效场景 | 默认参数 | Reduce Motion 降级方案 |
|---|---|---|
| 全屏层出现 | 背景磨砂与透明度 `0 → 1`（`420 ms`，`easeOut`）；中央内容 `scale 0.985 → 1` + `opacity 0 → 1`（`380 ms`，延迟 `60 ms`） | 取消缩放，仅保留 `220 ms` 纯淡入 |
| 全屏层关闭 | 整体 `opacity 1 → 0`（`260 ms`，`easeIn`） | 保持 `180 ms` 纯淡出 |
| 倒计时环推进 | 连续平滑线性更新（每秒或每 0.25s `linear` 插值） | 按整秒静默步进，无连续呼吸动画 |
| 1 分钟预告出现 | 右上角轻滑入 `translateY(-8 pt) → 0` + `opacity 0 → 1`（`300 ms easeOut`） | 取消位移，仅 `200 ms` 淡入 |

## 8. 可访问性规范（Accessibility）

1. **对比度**：浅色与深色模式所有正文、副文案、按钮文字均满足 WCAG 2.1 AA（≥ 4.5:1），主标题与大号倒计时满足 AAA（≥ 7:1）。磨砂背景叠加高不透明度色罩（84%–86%），防止浅色或高饱和壁纸穿透导致可读性下降；当系统开启「降低透明度（Reduce Transparency）」时，全屏层直接回退为 100% 不透明实色背景（浅 `#F2F4F2` / 深 `#161A19`）。
2. **VoiceOver 标签与播报**：
   - 菜单栏图标：`accessibilityLabel("整点歇")`，`accessibilityValue("下次休息 11 点 00 分，今天已完成 3 次")`（暂停态播报恢复时间）。
   - 全屏提醒弹出时：发送 `NSAccessibility.post(element:notification:.announcementRequested)` 播报「到整点了，休息 5 分钟，倒计时结束后自动关闭」；完成时播报「休息完成」。
   - 倒计时文本：在休息进行中避免每秒触发 VoiceOver 朗读造成刷屏，改为仅在用户主动聚焦时读取当前剩余时间，并在最后 10 秒或完成时播报一次。
3. **键盘全操作支持**：
   - 全屏层：不绑定 `Return` / `Esc`，避免弹出时正在打字误触；「提前结束」是标准按钮，可用 `Tab`（开启「键盘导航」时）聚焦后按空格触发。
   - 弹出面板与设置窗口：完整支持原生 `⌘,`（设置）、`⌘Q`（退出）、`Tab` 导航与方向键切换 Segmented Control。
4. **减弱动态效果（Reduce Motion）**：监听 SwiftUI `@Environment(\.accessibilityReduceMotion)`，按第 6.4 节表格自动降级。

## 9. 开发者 SwiftUI / AppKit 实现提示

> 以下为原生组件与系统 API 选型建议，不提供完整业务代码。

### 9.1 菜单栏常驻与设置窗口
- **隐藏 Dock 图标**：在 `Info.plist` 中设置 `LSUIElement = YES`（Application is agent）。
- **菜单栏入口**：macOS 13+ 直接使用 SwiftUI `MenuBarExtra` 搭配 `.menuBarExtraStyle(.window)` 构建弹出面板；若需精细控制菜单栏图标透明度/动态文本排版，可保留 `NSStatusItem` + `NSPopover`（`behavior = .transient`）。
- **设置窗口**：使用 SwiftUI `Settings` Scene 配合 `Form { Section(...) { ... } }.formStyle(.grouped)`，自动获得 macOS Ventura/Sonoma 原生分组表单视觉与 `⌘,` 快捷键；在 `MenuBarExtra` 内打开设置时，需先调用 `NSApp.activate(ignoringOtherApps: true)` 再触发 `openSettings` 环境动作，否则设置窗口可能被置于后台。

### 9.2 多显示器全屏覆盖层（核心难点提示）
- **窗口类选择**：建议使用自定义 `NSPanel` 或无边框 `NSWindow`（`styleMask: [.borderless, .nonactivatingPanel]` 或 `.borderless` 视主/副屏而定——主屏需能接收键盘事件，应重写 `canBecomeKey` 返回 `true`；副屏 `canBecomeKey` 返回 `false`）。
- **覆盖全屏应用与所有空间**：
  - `level`：使用 `.screenSaver` 或 `NSWindow.Level(rawValue: Int(CGWindowLevelForKey(.statusWindow)) + 1)`，确保盖住菜单栏与 Dock，同时不干扰系统强制退出面板。
  - `collectionBehavior`：设为 `[.canJoinAllSpaces, .fullScreenAuxiliary, .stationary, .ignoresCycle]`。
  - `setFrame(screen.frame, display: true)`：为 `NSScreen.screens` 中的每块屏幕各创建一个窗口；通过 `NSEvent.mouseLocation` 判定当前光标所在屏作为主交互屏，其余作为静默同步屏。
  - 监听 `NSApplication.didChangeScreenParametersNotification` 处理显示器热插拔。
- **原生磨砂背景**：使用 `NSVisualEffectView` 封装为 `NSViewRepresentable`（`material = .hudWindow` 或 `.fullScreenUI`，`blendingMode = .behindWindow`，`state = .active`），并在其上方叠加 SwiftUI 半透明色罩 `surface.overlayScrim`；同时监听 `@Environment(\.accessibilityReduceTransparency)` 切换为纯色底。

### 9.3 整点前 1 分钟预告胶囊
- 使用独立的无边框 `NSPanel`（`styleMask: [.borderless, .nonactivatingPanel]`，`level = .floating`，`collectionBehavior = [.canJoinAllSpaces, .fullScreenAuxiliary, .transient]`，`hidesOnDeactivate = false`）。
- 计算 `mainScreen.visibleFrame` 的右上角坐标（`maxX - width - 16`, `maxY - height - 12`），这样自动避开菜单栏高度（含刘海屏安全区），且弹出时不抢夺用户当前编辑器的键盘焦点。

### 9.4 系统集成与状态检测
- **开机自启动**：使用 macOS 13+ 原生 `ServiceManagement` 框架的 `SMAppService.mainApp.register()` / `unregister()`，无需旧版 Helper App，且直接与「系统设置 → 登录项」双向同步。
- **提示音**：使用 `NSSound(named:)` 播放系统内置轻柔音效（如 `"Glass"` / `"Tink"` 或打包极小自定义木琴 `.aiff` 文件），避免引入重型音频框架。
- **休眠与唤醒**：订阅 `NSWorkspace.shared.notificationCenter` 的 `willSleepNotification` 与 `didWakeNotification`，唤醒后重置整点计时器并丢弃过期触发。
- **会议 / 全屏演示检测（渐进方案，免侵入隐私权限）**：
  1. **独占全屏检测**：检查 `CGDisplayIsCaptured(CGMainDisplayID())`（游戏/全屏演示）或通过 `CGWindowListCopyWindowInfo(.optionOnScreenOnly, kCGNullWindowID)` 判断最前应用窗口尺寸是否等于屏幕完整尺寸（排除桌面与自身）。
  2. **摄像头活跃检测**：可通过 CoreMediaIO（`kCMIOHardwarePropertyDevices` + `kCMIODevicePropertyDeviceIsRunningSomewhere`）检测是否有其他应用正在使用摄像头（视频会议），无需向用户索取摄像头权限！
  3. **专注模式 / 屏幕共享**：如检测到 `ScreenCaptureKit` 或常见会议进程（Zoom / Teams / Meet / 腾讯会议 / 飞书会议）处于通话/共享态，可作为补充开关策略。
- **精准整点调度**：不要用每秒漂移累加的计时器；每次计算下一个整点的绝对 `Date`，配合 `DispatchSourceTimer` 或 `Timer(fire:interval:repeats:)`，并在系统唤醒及 `NSSystemClockDidChange` 时重新校准。
